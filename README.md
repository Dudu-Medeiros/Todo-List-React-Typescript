# ✅ Todo List — Gerenciador de Tarefas

Uma aplicação web desenvolvida com **React e TypeScript** para gerenciamento de tarefas diárias. O objetivo do projeto é colocar em prática conceitos de desenvolvimento front-end, tipagem estática e gerenciamento de estados no React.

## 🚀 Sobre o projeto

O Todo List é uma aplicação simples e intuitiva que permite ao usuário organizar suas atividades, acompanhar tarefas concluídas e manter sua rotina mais organizada.

O projeto foi desenvolvido como exercício prático para consolidar conhecimentos em React e TypeScript, utilizando componentes reutilizáveis, interfaces, propriedades tipadas e manipulação de estados.

## ✨ Funcionalidades

- [ ] Adicionar novas tarefas.
- [ ] Marcar tarefas como concluídas.
- [ ] Editar tarefas existentes.
- [ ] Excluir tarefas individualmente.
- [ ] Remover todas as tarefas concluídas.
- [ ] Exibir a quantidade total de tarefas.
- [ ] Exibir a quantidade de tarefas concluídas.

## 🛠️ Tecnologias utilizadas

- **React:** construção da interface através de componentes.
- **TypeScript:** tipagem estática e maior segurança no desenvolvimento.
- **CSS3:** estilização e responsividade da aplicação.
- **Vite:** ambiente de desenvolvimento e build.

## 🎨 Identidade visual

A interface utiliza uma paleta escura com tons de roxo como cor de destaque, proporcionando uma aparência moderna e minimalista.

| Cor | Código | Aplicação |
| :--- | :--- | :--- |
| Background | `#0B1020` | Fundo principal |
| Surface | `#121A2B` | Card principal |
| Primary | `#6D4AFF` | Botões e destaques |
| Secondary | `#A6B0C5` | Textos secundários |
| Success | `#35C98A` | Tarefas concluídas |
| Danger | `#FF5B68` | Ações de exclusão |

## 💻 Como executar o projeto

**1. Clone o repositório**
```bash
git clone https://github.com
```

**2. Entre na pasta do projeto**
```bash
cd Todo-List-React-Typescript
```

**3. Instale as dependências**
```bash
npm install
```

**4. Execute a aplicação**
```bash
npm run dev
```

## 📚 Conceitos praticados

Durante o desenvolvimento, foram explorados os seguintes conceitos:

- Componentização no React.
- Hooks, especialmente `useState`.
- Interfaces e tipagem com TypeScript.
- Props e comunicação entre componentes.
- Manipulação de arrays com `map`, `filter` e `find`.
- Eventos e funções tipadas.
- Renderização condicional.
- Organização e reutilização de código.
